# Studio Overview

OpenFini has six studios that share one document. This page compares them, explains the shortcuts that are common to all of them, and describes how studios are listed in the header. Each studio has its own page with tools, panels and shortcuts.

## Comparison

| Studio | Toolbox and workspace | Typical output | Page |
| --- | --- | --- | --- |
| Vector | Pen, node, shapes, gradients, text | SVG, PNG, PDF | [[Vector Studio]] |
| Pixel | Selections, brushes, retouching, adjustments, filters, histogram | PNG, JPEG, WebP, PSD | [[Pixel Studio]] |
| Layout | Pages, masters, flowing text, tables, charts | PDF with bleed and crop marks | [[Layout Studio]] |
| Code | Editor, visual designer, Git, publishing | Static website, Markdown or LaTeX pages | [[Code Studio]] |
| Vibe | Chat, activity, models, tools, skills, knowledge | Anything the other studios make | [[Vibe Studio]] |
| Office | Formatting toolbar, outline, pages | DOCX, ODT, RTF, PDF, HTML, Markdown | [[Office Studio]] |

## Switching

Use the header buttons or `Alt+1` to `Alt+5` (following the header order). The Studio menu lists every studio, including those in *More*. The header shows at most five (preference `visibleStudios`, default Vector, Pixel, Layout, Code, Vibe); Office starts in the *More* menu. Opening a *More* studio shows it in the place of the *More* label until you pick another one. Add a studio to the header in *Settings ▸ Studios* (at least one, never more than five) to give it an `Alt` shortcut.

## Shortcuts common to all studios

`Mod` is `Ctrl` on Windows and Linux, `Cmd` on macOS. The complete generated list is on [[Keyboard Shortcuts]].

| Action | Shortcut |
| --- | --- |
| New / Open / Save / Save As | `Mod+N` / `Mod+O` / `Mod+S` / `Mod+Shift+S` |
| Export / Place image | `Mod+Shift+E` / `Mod+Shift+P` |
| Undo / Redo | `Mod+Z` / `Mod+Shift+Z` or `Mod+Y` |
| Cut / Copy / Paste / Paste in place / Duplicate | `Mod+X` / `Mod+C` / `Mod+V` / `Mod+Shift+V` / `Mod+J` |
| Select all / Deselect / Delete | `Mod+A` / `Mod+D` / `Delete` |
| Group / Ungroup | `Mod+G` / `Mod+Shift+G` |
| Zoom in / out / 100% / fit page / fit selection | `Mod+=` / `Mod+-` / `Mod+1` / `Mod+0` / `Mod+Shift+0` |
| Pan | hold `Space` and drag, middle mouse, or two-finger scroll |
| Rulers / Grid / Guides | `Mod+R` / `Mod+'` / `Mod+;` |
| Command palette | `Mod+K` |
| All shortcuts | `F1` |

Drag from a ruler to make a guide and drag it back to remove it. Hold `Ctrl` while dragging to turn snapping off for that move. While drawing and transforming, `Shift` constrains (uniform scale, squares, circles), `Alt` works from the center (or copies when moving), and `Ctrl` skips snapping and selects deep.

## Text editing on the canvas

Click into text to edit. Arrows, `Home`/`End`, `Mod`+arrows by word and `Shift` to select work as usual; double-click selects a word, triple-click a paragraph. `Mod+B`, `Mod+I` and `Mod+U` toggle bold, italic and underline; everything else is in the **Type** panel. Copy and paste keep formatting inside OpenFini and fall back to plain text elsewhere; `Esc` leaves text editing.

## Panels, docks and workspaces

Each studio has panels in docks (Appearance, Transform, Color, Type, Layers, History, Navigator, and studio-specific ones). Show, hide and place them in *Settings ▸ Layout and workspaces*, and save your own workspace per studio ([[Customization and Profiles]]).
