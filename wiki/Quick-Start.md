# Quick Start

This page takes you from a fresh install to an exported file in about ten minutes: create a document, draw, switch studios, use the command palette, export and save. Each step names the menu or shortcut so you can follow along with the keyboard or the mouse. `Mod` means `Ctrl` on Windows and Linux and `Cmd` on macOS.

## 1. Create a document

Press `Mod+N` (*File ▸ New…*). The dialog has a *Start in* row with a card per studio and sizes for each. Pick **Vector** and a preset such as a poster size, then confirm. A first launch also shows a small tour invitation (*Start the tour*, *Not now*, *Don't show tours*); it never blocks you.

## 2. Draw

In the Vector studio:

1. Press `M`, drag a rectangle (hold `Shift` for a square).
2. Press `T`, click, and type a heading.
3. Press `V` for the Move tool, select the rectangle, and open the **Appearance** panel to change fill and stroke.
4. Press `Mod+Z` to undo anything; every change is undoable.

Pan by holding `Space` and dragging; zoom with `Mod+=` and `Mod+-`; `Mod+0` fits the page. See [[Vector Studio]] for all tools.

## 3. Switch studios

`Alt+1` to `Alt+5` switch between the studios in the header. The document keeps all its content: a Layout page can hold vector shapes and pixel layers. Switch to **Layout** and press `T` to draw a text frame that can flow across pages ([[Layout Studio]]). Studios in the *More* menu (Office) have no shortcut until you add them to the header in *Settings ▸ Studios*.

## 4. Use the command palette

`Mod+K` opens the global command palette; type "export" or "histogram" and press `Enter`. It lists only the commands that can run right now. `F1` lists all keyboard shortcuts and `Shift+F1` turns on **What's this?**: click any control to read what it does.

## 5. Export

Press the **Export** button in the header (`Mod+Shift+E`). Choose PNG, JPEG, WebP, SVG or PDF, set scale and quality, and save. For a quick export with default settings use *File ▸ Quick Export*. See [[Export and Publish]].

## 6. Save

`Mod+S` writes an `.ofini` file: a ZIP that keeps every page, layer, text story and website file ([[Concepts]]). If you opened a `.txt`, `.docx` or `.svg` with *File ▸ Open*, Save writes that same format instead ([[Save in Original Format]]). OpenFini also autosaves a recovery session on your device; *Settings ▸ General* controls autosave and whether the last session is restored on start.

## Try a second studio

| Goal | Steps |
| --- | --- |
| Edit a photo | `Mod+O` a JPEG or PNG. It opens in the Pixel studio. Open the **Adjust** panel, add Levels, and watch the histogram ([[Pixel Studio]]). |
| Build a page | *File ▸ New ▸ Code*, choose the Landing page template, edit text on the canvas, `Mod+Shift+E` for the website export ([[Code Studio]]). |
| Write a letter | *More ▸ Office Studio*, choose the Letter template ([[Office Studio]]). |
| Ask an assistant | Turn on *Settings ▸ Artificial intelligence*, open Vibe (`Alt+5`), choose the offline Demo model, and type a request ([[Vibe Studio]]). |
