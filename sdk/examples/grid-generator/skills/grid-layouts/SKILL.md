# Grid layouts

1. Decide the page size first (list the layers or ask for the document info).
2. Call the extension tool for grids with sensible numbers: cells of 24-96 px, gaps of 8-24 px, at most 400 cells.
3. If the result needs variety, select the group and recolor single cells with set_style.
4. Keep the grid group intact; align other layers to it instead of ungrouping.
