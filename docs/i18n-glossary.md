# Translation glossary

Agreed terms so every translator (and every future language) stays consistent. The German column is the reference
for `locales/de.json`.

## Style (German)

* Menu items, buttons and commands use the **infinitive**: "Speichern unter…", "Datei öffnen". No "Sie".
* Descriptions may address the reader with "du" where the English says "you"; prefer impersonal phrasing when it is as short.
* Keep the ellipsis `…` when the command opens a dialog. Keep shortcuts in the platform style (Strg, Umschalt, Alt, Cmd).
* Placeholders (`{name}`) and plural branches stay intact; the check fails on a mismatch.
* Do **not** translate: product and studio names (OpenFini, Vector, Pixel, Layout, Code, Vibe), file formats, "Pixel"/"px",
  "Layout", "Vibe", "Git", "Commit", "Branch", "MCP", "Skill" (used as a noun), technical identifiers and URLs.
