  and video. Its studios share one document, so a project can mix vector shapes, pixel layers, flowing text and a
  website. The desktop app is built with Tauri on the operating system's own web view, which keeps installers at a
  few megabytes, and the same app runs in the browser as an installable web app. OpenFini needs no account, sends no
  telemetry and keeps files on the user's device; its AI assistant, Vibe, is off by default and works with the
  provider or local model the user chooses. OpenFini is MIT licensed and developed in the open on GitHub.

## Contact {contact}

For questions, open an issue on [GitHub](https://github.com/philppplik/open-fini/issues). There is no press office;
the project is run by its maintainers.
