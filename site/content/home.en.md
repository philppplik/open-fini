## Light {light}

No framework and no bundled browser: the desktop app is a Tauri shell around the system's own web view. A production
build paints first in {fcp} and starts with only the core code; the Code and Vibe studios load when you open them.
Weak hardware gets a low-power mode automatically.

## Private {private}

Everything stays on your device. After installation the app makes no network calls of its own. AI is off by default,
and when you connect a model, requests go only to the provider you chose.

## Open {open}

MIT licensed and developed in the open. OpenFini is a clean-room implementation: no code, assets or file formats from
proprietary products.
